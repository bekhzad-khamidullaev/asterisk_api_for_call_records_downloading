# asterisk_api_for_call_records_downloading

Python API для получения записей звонков Asterisk сторонними приложениями.

## Структура

- [`get_audio.py`](get_audio.py)

## Использование

Точка входа — [get_audio.py](get_audio.py). Перед запуском уточните Python-зависимости, способ запуска API, настройки доступа и путь к записям. Файл зависимостей в корне отсутствует; готовность к запуску в чистом окружении не подтверждена.
